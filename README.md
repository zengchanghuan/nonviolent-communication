# 沟通学习笔记

这是一个用于自我学习沟通的仓库，以非暴力沟通（Nonviolent Communication，NVC）为主要学习方向，记录概念理解、表达练习和真实情境中的复盘。

希望通过持续练习，更清楚地理解自己、更认真地倾听他人，并把想法、感受、需要和边界表达出来。

## 阅读材料与当前进度

1. [《非暴力沟通》英文第 3 版](<Nonviolent Communication (Marshall B. Rosenberg).epub>)，Marshall B. Rosenberg 著，2015 年出版。当前先读这本书。
2. [《高难度谈话》英文版](<Difficult Conversations How to Discuss What Matters Most (Douglas Stone  Bruce Patton  Sheila Heen).epub>)，Douglas Stone、Bruce Patton、Sheila Heen 著。尚未开始。

接续学习时，先查看 [当前学习进度](PROGRESS.md)。

## 学习目标

- **理解自己**：辨认当下的感受，以及感受背后的需要。
- **清楚表达**：描述具体发生的事情，减少笼统的评价和指责。
- **倾听他人**：尝试理解对方的感受和需要，并向对方确认自己的理解。
- **处理分歧**：提出具体、可回应的请求，同时尊重双方的选择和边界。
- **形成习惯**：将所学用于日常交流，通过复盘逐步调整。

## 学习主线

从非暴力沟通的四个要素开始练习：

| 要素 | 练习时关注的问题 |
| --- | --- |
| 观察 | 具体发生了什么？哪些是可观察的事实，哪些是我的判断？ |
| 感受 | 此刻我有什么感受？ |
| 需要 | 这些感受背后，我在意或需要什么？ |
| 请求 | 我希望对方采取什么具体行动？是否也愿意听到拒绝并继续协商？ |

这四个要素可以帮助梳理思路，实际交流时根据情境自然表达，不必每次都套用完整句式。

## 学习方式

以原书为主线，按章节学习，每轮按内容连贯性合并数段，给出较充分的译文，不再默认一次只读一段；短小节可以一次读完。先讲解，尽量不向学习者提问，不把回答问题作为继续学习的条件；学习者可以随时要求继续、深入讲解或结合具体情境分析。

1. **对照原文**：读取本地英文书，标明章节和段落，展示原文。
2. **忠实翻译**：尽量保留原文的意思、逻辑、语气和例子；不擅自补充，有歧义时明确说明。
3. **分开讲解**：将译文与教练的解释分开，用简洁中文说明必要的概念。
4. **讲解与示例**：先讲清当前段落的意思，再按需要用一个具体例子说明；尽量不提问，练习按学习者的要求安排。
5. **记录停点**：保留已读内容、学习者的回答和待完成的问题，方便下次接着学习。

讲解表达方式时，可以直接给出示例并解释改写依据；学习者要求自主练习时，再让其先尝试并按需要提供提示。反馈应保留合理诉求和边界，不编造事实、承诺、情绪、歉意或让步。判断表达是否合适时，同时考虑事实、清晰度、尊重和边界。

## 练习与复盘模板

```text
日期与情境：
具体发生的事情：
我的第一反应或原话：
我的感受：
我在意的需要或边界：
我对对方感受和需要的猜测（有待确认）：
我想提出的具体请求：
我准备如何表达：
实际交流与对方的回应（如有）：
这次的发现与下次想尝试的一个小改变：
```

## 记录原则

- 用自己的话记录，保留真实的疑问和思考过程。
- 区分已经发生的事实、自己的解释，以及尚未确认的猜测。
- 区分书面练习与实际交流经验，逐步积累反馈。
- 根据学习需要逐步添加笔记和练习材料。
